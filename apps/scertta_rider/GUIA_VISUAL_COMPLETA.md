## 📊 13. Dashboard de Métricas (Futuro)

Queries SQL para analizar el negocio:

### Distribución de Planes

```sql
SELECT 
  plan_conductor,
  COUNT(*) as conductores,
  ROUND(COUNT(*) * 100.0 / SUM(COUNT(*)) OVER (), 2) as porcentaje
FROM perfiles
WHERE rol = 'conductor'
GROUP BY plan_conductor;
```

**Resultado Esperado**:
```
plan_conductor | conductores | porcentaje
---------------|-------------|------------
comunidad      | 800         | 80.00%
vip            | 200         | 20.00%
```

### Ingresos por Plan VIP

```sql
SELECT 
  COUNT(*) as conductores_vip,
  COUNT(*) * 25000 as ingreso_semanal,
  COUNT(*) * 25000 * 4 as ingreso_mensual
FROM perfiles
WHERE plan_conductor = 'vip';
```

**Resultado Esperado**:
```
conductores_vip | ingreso_semanal | ingreso_mensual
----------------|-----------------|------------------
200             | $5.000.000      | $20.000.000
```

### Conductores por Nivel

```sql
SELECT 
  nivel_conductor,
  COUNT(*) as cantidad
FROM estadisticas_conductores
GROUP BY nivel_conductor
ORDER BY cantidad DESC;
```

**Resultado Esperado**:
```
nivel_conductor | cantidad
----------------|----------
Intermedio      | 450
Novato          | 300
Avanzado        | 180
Experto         | 60
Maestro         | 8
Leyenda         | 2
```
