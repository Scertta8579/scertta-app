Infraestructura híbrida

Failover automático local↔cloud con réplica PostgreSQL en tiempo real

🖥️ ZimaOS Server

Servidor físico en Buenos Aires. 19GB RAM, PostgreSQL 17, Valhalla routing, Martin tiles.

☁️ Supabase Cloud

Base de datos en la nube con 176 políticas RLS. Réplica lógica pull desde ZimaOS.

🔄 Failover <2s

Si el servidor local cae, las apps cambian a Supabase Cloud automáticamente. Health check cada 15s.

🗺️ Mapas self-hosted

Valhalla routing engine + Martin vector tiles. Sin dependencia de APIs externas de mapas.

🧠 Ollama + llava:13b

Visión artificial para validación KYC de documentos. Modelo local, sin costo por inferencia.

💰 ARCA integrado

Facturación post-pago con riesgo fiscal argentino documentado. Conciliación en 3 pasos.
